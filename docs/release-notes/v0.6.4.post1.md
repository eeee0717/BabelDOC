# BabelDOC Stream v0.6.4.post1

This is the first independent BabelDOC Stream release, based on upstream
BabelDOC v0.6.4 commit `17480db9df92ddcb37349ce34b312335226e8ec9`.

## Changes

- Publish the project as the `babeldoc-stream` Python distribution with the
  collision-free `babeldoc-stream` executable.
- Add `--progress-json` for the stable `babeldoc-stream/v1` JSON Lines protocol.
- Keep human-readable logs on stderr while reserving stdout for protocol events.
- Exit non-zero after a terminal translation error and request graceful
  cancellation on SIGINT or SIGTERM.
