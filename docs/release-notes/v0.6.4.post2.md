# BabelDOC Stream v0.6.4.post2

This release extends the host protocol without changing the default v1 output.

## Changes

- Add opt-in `babeldoc-stream/v2` events through `--progress-json-version 2`.
- Report initialization, model loading, and streamed asset-download progress.
- Include stable stage codes, stage-local progress, and monotonic overall progress.
- Stream downloads through verified temporary files instead of buffering whole assets.
- Keep `--progress-json` on v1 by default for existing host applications.
